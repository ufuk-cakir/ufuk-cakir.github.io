# Fonts

## EBGaramond-Initials.otf

EB Garamond Initials — foliate **woodcut** decorative initial capitals, the
companion to the EB Garamond body type. Used for the drop caps.

- Designers: Georg Mayr-Duffner and Octavio Pardo
- Reserved Font Name: "EB Garamond"
- License: SIL Open Font License, Version 1.1 — <https://scripts.sil.org/OFL>

Note: it only decorates ~11 letters (A D F G I L N Q T U X); a first-letter
outside that set falls back to plain EB Garamond. (That's why the "Essays"
title, starting with E, has a plain initial rather than a woodcut one.)

The SIL OFL permits redistribution and web embedding. For a verbatim license,
add `OFL.txt` here from <https://github.com/octaviopardo/EBGaramond12>.
